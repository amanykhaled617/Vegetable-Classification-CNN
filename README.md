# Vegetable Classification using CNN

A Convolutional Neural Network (CNN) project in Python/Keras for classifying vegetable images, trained on Google Colab for 20 epochs with `ModelCheckpoint` saving the best model (`best_vegetable_cnn.keras`) based on `val_loss`.

## Results
- **Best Validation Loss:** `0.06080` (saved at Epoch 19)
- **Validation Accuracy:** ~`97.7%` – `98.3%`
- **Training Accuracy:** ~`94.9%`

## Files in this Repository
- `Untitled1.ipynb`: Full training code, evaluation metrics, and accuracy/loss plots.
